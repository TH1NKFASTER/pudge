## Milestone 4 — native Swift safety audit

Проверены Apple-specific участки, которые Linux `swiftc -parse` не typecheck-ит против iOS SDK. Удалено использование `MPNowPlayingInfoCenter.playbackState`: Apple документирует это свойство как macOS-only; на iOS состояние уже передаётся через `nowPlayingInfo` и `MPNowPlayingInfoPropertyPlaybackRate`.

Дополнительно исправлены три native runtime-сценария:
- неуспешный старт плеера теперь снимает active protection со всех уже защищённых частей, очищает `AVPlayer`/book/session и не оставляет книгу «занятой»;
- ручная пауза фоновой загрузки использует cancel с resume-data и сохраняет его в `TransferRecord`;
- если итоговый файл уже существует, но не проходит хеш/размер, успешная новая загрузка заменяет повреждённый файл вместо вечного цикла `failed`.

Ручной HTTPS-адрес Mac теперь так же, как QR-подключение, отвергает user/password/query/fragment.

Добавлены `tests/test_iphone_native_swift_guards.py` и дополнительный guard в `scripts/check_ios_project.py` против возврата macOS-only Now Playing API. Проверки: iOS structural checker PASS; Swift Core 15/15; iPhone/Mac + native guards 45/45; все native Swift-файлы `swiftc -parse` PASS. Xcode/Apple SDK по-прежнему нужны для окончательного typecheck/build.

## Перенос десктопной части в main (04.10.2026)

Десктопная часть milestone 5 перенесена на текущий main (после 0.7.30). Исправлено по ревью:
- каталог: оригиналы, которые iPhone играет нативно, отдаются на месте (без копии библиотеки), хеши и подготовка кешируются по size+mtime, подготовка идёт в фоне — запрос каталога ждёт не дольше 10 с;
- Range-запросы не перехешируют весь файл; архивирование хеширует вне общего замка (плеер Mac не замирает);
- данные iPhone лежат рядом с базой (`~/.local/share/pudge/iphone`), не в `~/.config`;
- устаревшее событие (книга удалена, новая редакция, восстановленная база) получает окончательную квитанцию `rejected` вместо вечного 409;
- живой сеанс Mac сохраняется после переключения доступа; сеанс, отданный на iPhone, больше не создаёт ветку; кандидат конфликта — один на сеанс;
- перемотка остановленного плеера Mac — общая позиция; прослушанное на Mac при выключенном доступе не откатывается;
- уже стоящий на паузе iPhone передаёт прослушивание на Mac без ожидания подтверждения;
- HTTP: на любую ошибку есть ответ, ошибки во время отдачи файла не дописывают JSON, ответы с ошибкой закрывают соединение;
- удалённая на Mac книга исчезает из каталога (архивы с телефона остаются).
