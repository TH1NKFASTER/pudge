# OCR regression fixtures

OCR regressions use procedural pages generated by PIL (`Image.new`, `ImageDraw`)
inside the test. Do not commit scans, screenshots, extracted page OCR JSON,
private acceptance corpora or fixture paths supplied through environment variables.
A real failure should be reduced to its physical cause, then recreated with
invented shapes, geometry and text. Changes to an OCR post-processing rule should
include both the failing scene and a nearby case where the rule must do nothing.

`synthetic_ocr.py` draws separate, fused and clipped glyph-like ink bands and a
main-print lane next to furigana. The v96p27, v96p28, v96p29 and v96p34 regressions
exercise physical detection, crop agreement, overlap, cleanup, punctuation and art
connections. `test_v21_synthetic_ocr_regressions.py` replaces the private donor,
art-retry and verified-output acceptance cases. Coordinate translations and scale
variations prevent tying these checks to a particular page number or screenshot.

Image-dependent guards run on these generated pixels. Recognizer outputs are
controlled invented readings, including disagreement and empty/Latin readings;
the test suite does not download an OCR model. Metadata-only and UI tests may
construct synthetic region dictionaries directly. These tests verify detector,
geometry, selection and serialization behavior; they do not measure a neural
recognizer's accuracy on published pages.

Run the suite with `python -m pytest tests`. `install.sh --update` runs it as a
mandatory step, in isolated application state. `pudge/ocr_fixture_policy.py`
also rejects retired private tests, page/image/archive fixtures in the test tree,
unmarked OCR region JSON and private fixture environment dependencies. A skipped
OCR test for missing page materials is an installation failure. Platform-only
skips remain valid where the platform is unavailable.

The v21 patch removes the four retired private test modules from old local
checkouts and moves their known in-tree fixture directories into its ignored
`.patch-backups` directory. It does not change the user's book library or page
caches. Backups must not be included in releases or published to a repository.
